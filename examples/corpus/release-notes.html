Rover firmware 4.2

Firmware 4.2 is a maintenance release for the L2 rover. Install it from the depot console; the update takes about 12 minutes and the rover restarts twice.

What changed

  • Kerb detection now works in heavy rain.
  • The rover slows to walking pace within 3 metres of a pedestrian.
  • Fixed a fault where code E27 was raised by morning dew.

Compatibility

Hardware revisionSupportedNotes
L2 rev AYesNeeds bootloader 1.9 or newer
L2 rev BYes
L1NoStay on firmware 3.x

Rolling back

If a rover misbehaves after the update, roll back from the console:

rover-ctl firmware rollback
rover-ctl firmware status

Rollback keeps maps & delivery history.

Larkspur Robotics is a fictional company used for example data.
